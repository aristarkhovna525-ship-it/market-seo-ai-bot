# Telegram-бот: ИИ-Копирайтер для Маркетплейсов (SEO-генератор)

Асинхронный Telegram-бот на базе фреймворка **Aiogram 3** и нейросети **GPT-4o-mini** (через интеграцию с ProxyAPI). Бот предназначен для автоматического создания продающих, оптимизированных и привлекательных SEO-описаний товаров для маркетплейсов (Wildberries, Ozon) по переданным характеристикам.

## 🚀 Основной функционал

* **AI SEO-генерация:** Автоматическое составление продающих текстов с ключевыми словами, делением на абзацы и эмодзи.
* **Система монетизации и лимитов:** 
  * 2 бесплатные генерации для новых пользователей.
  * Интеграция ручной проверки платежей (пользователь отправляет скриншот чека, администратор одобряет/отклоняет операцию через инлайн-кнопки прямо в чате).
  * Премиум-подписка на 30 дней с безлимитным доступом к ИИ.
* **Безопасность:** Конфиденциальные данные (токены, API-ключи, реквизиты) полностью вынесены в переменные окружения (`.env`).

## 🛠 Технологический стек

* **Язык программирования:** Python 3.10+
* **Фреймворк для бота:** Aiogram 3.x (Асинхронный)
* **Интеграция с ИИ:** OpenAI API Client (работа через эндпоинты ProxyAPI)
* **Работа с окружением:** Python-dotenv

## 📦 Инструкция по локальному развертыванию

1. Клонируйте репозиторий.
2. Установите зависимости проекта:
   ```bash
   pip install -r requirements.txt
   ```
3. Создайте в корневой директории файл `.env` и заполните его своими данными:
   ```text
   TELEGRAM_TOKEN=ваш_токен_бота
   PROXYAPI_KEY=ваш_ключ_ai
   ADMIN_ID=ваш_id_в_телеграм
   CARD_NUMBER=номер_карты_для_оплаты
   BANK_NAME=название_банка
   RECEIVER_NAME=Имя_Получателя_Перевода
   ```
4. Запустите бота:
   ```bash
   python main.py
   ```
